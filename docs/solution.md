# Solution

Interview Coach is a Microsoft Copilot Studio agent.

The solution will:

1. Use SharePoint as a knowledge source.
2. Generate role-specific interview questions.
3. Analyze candidate skill gaps.
4. Create 7-day learning plans.
5. Integrate with Power Automate.
6. Deploy inside Microsoft Teams.

Target Users:

- Students
- Graduates
- Job Seekers
- Internal Employees
